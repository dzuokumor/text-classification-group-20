# LSTM Text Classification Models

This folder contains experiments using LSTM-based models for text classification.

## Implemented Models
- TF-IDF + Neural Network (baseline)
- Word2Vec + LSTM (trained embeddings)
- GloVe + LSTM (pretrained embeddings)

## Notebook
- `lstm_embeddings.ipynb`: end-to-end pipeline including preprocessing, training, evaluation, and comparison.

## Notes
- Models are evaluated using Accuracy, Precision, Recall, and F1-score.
- Validation split: 80/20
